- 🟢 Single letters
- 🟡 Batchim (final consonants)

With timer pressure, streak logic, adaptive difficulty and multiple game modes.

HANGUESS is a **Progressive Web App (PWA)**.

# 🎯 Game Modes

HANGUESS offers 3 distinct ways to practice, each with its own mechanics:

## 📖 Reading Mode

- Shows progress per character.
- Adaptive difficulty.
- Mistakes increase required repetitions.
- Type the romanization matching the Korean character visually.

## 🎧 Listening Mode

- Infinite progressive queue (Letters → Batchim → Syllables → Words).
- Korean character is hidden `?`.
- Auto-plays the pronunciation audio.
- One mistake = Game Over! Track your streak!

## 🎙️ Speaking Mode

- Validates your speech using the microphone (Web Speech API).
- Showcases the Korean character on screen.
- You must pronounce it correctly to advance before the timer runs out!
- One mistake = Game Over!
